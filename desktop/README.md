# Range Calculator Desktop (desktop)

`range_calculator` の物理シミュレーション（**弾道・軌道・多体**）を、ブラウザを使わずに
ネイティブ GUI で操作・可視化するデスクトップアプリです。GUI は Python 標準ライブラリの
Tkinter（ttk）で構築し、物理計算は既存の `range_calculator`（`ballistics` /
`orbital` / `nbody` / `physics_config`）をそのまま再利用します。

対応 OS は **Windows 11（主）** と **macOS（副）** です。実行時依存は Python 標準
ライブラリのみで、追加の `pip` パッケージは不要です（ビルド時のみ PyInstaller を
使います。§4）。

機能は `webapp` と同等です（入力・Result メトリクス・軌跡チャート）に加え、デスクトップ
だけの **多体（N-body）ウィンドウ**を持ちます。GUI は用途別に **3 つの独立したウィンドウ**
へ分かれています。

- **弾道（`ballistic_app.py`）**: 地表弾道。初速・発射角・抗力の密度モデルと、回転
  （Magnus 揚力。スピン回転数・スピン軸角）を指定できる。軌跡は断面（x–y）と上面
  （x–z）を切り替え可能。
- **軌道**（`orbital_app.py`）: 中心重力（ニュートン / ニュートン+J2）。軌道半径と
  軌道速度（既定は円軌道速度を自動設定）を指定する。
- **多体**（`nbody_app.py`）: 相互重力の多体シミュレーション。**太陽中心**・
  **地球中心**・**太陽・地球・月（3体）**の 3 つのプリセットを用意し、前者 2 つは
  中心天体 1 つだけで開始する。2 つ目以降の天体は**周回対象**（先行する天体を
  位置で指定。ラベルは「天体 1」「天体 2」…）と天体ごとの**天体カタログ**
  （太陽・惑星・月・**人工衛星**）から選ぶと、密度・半径と周回対象まわりの円軌道の
  初期条件がテキストボックスに読み込まれる。**高度 (m)** は周回対象の地表からの高さで、
  人工衛星だけでなく任意の天体に使える（例: 火星の周りに月を任意の高さで置く。
  空欄ならカタログ既定の距離）。天体の位置は「周回対象の現在座標＋（周回対象の半径＋
  高度）」で与えるため、太陽中心の系のまま地球（あるいは火星）のまわりに衛星や月を
  置くなど、系全体と局所軌道を混在できる。天体ごとの名前・体積密度・半径・初期状態・
  刻み幅・最大時間は自由入力で編集できる。μ は体積密度と半径から
  μ = G·ρ·(4/3)πr³ で導出され（実測値との誤差はごく小）、表示は読み取り専用。
  実行結果は全フレームを記録し、スライダーでフレーム送り・再生できる。**表示中心**を
  選ぶと、その天体を基準に描画するため、太陽系の中の地球周回のような小さな軌道も
  可視化できる。

共通のヘルパーは `app_common.py` に集約しています。対応関係と設計の詳細は
`desktop/PLAN.md` を参照してください。

## 1. 前提環境

- **Python 3.9 以上**（Windows: `python` / `python3`、macOS: `python3`）
- Tkinter（Python 同梱。Scoop の Python 3.15 / python.org 版で動作確認）
  - Tk のバージョン確認: `python3 -c "import tkinter; print(tkinter.TkVersion)"`

追加の `pip` パッケージは不要です。

---

## 2. 起動方法

リポジトリのルートで実行します。

Windows:

```powershell
python desktop/ballistic_app.py
python desktop/orbital_app.py
python desktop/nbody_app.py
```

macOS:

```sh
python3 desktop/ballistic_app.py
python3 desktop/orbital_app.py
python3 desktop/nbody_app.py
```

起動時に既定値（初速 170 km/h、発射角 35 deg、Cd 0.47、刻み幅 dt は弾道 0.01 s・軌道 1 s
など。多体はプリセット「太陽を中心とした多体問題」）で 1 回自動実行されます。

## 3. 操作方法

### 3.1 弾道ウィンドウ（`ballistic_app.py`）

1. **発射速度** と **発射角** のスライダーを動かす。
2. **抗力係数 Cd** は既定プロファイルの球体代表値 **0.47 に固定**（UI では読み取り専用の
   ラベル。プルダウンによる球種選択は廃止）。
3. **抗力（密度）モデル** を選ぶ（なし / 一様 / 指数 / 区分指数）。「なし」は抗力を
   無効化（`Cd=0`）する。
4. **スピン（Magnus 揚力）** の **回転数**（0–6000 rpm）と **スピン軸角**（-180–180 deg）
   を設定する。軸角 0 はバックスピン、+90 は *+z*、−90 は *−z*、±180 はトップスピン。
   回転数 0 で Magnus 効果は無効。
5. 必要に応じて **刻み幅 dt**（0.0001–10、0.0001 単位）を変更し、**adaptive** を
   有効にする。
6. **表示** を「断面 (x–y)」または「上面 (x–z)」（スピンによる左右のずれ）から選ぶ。
7. 「**シミュレーション実行**」を押す。計算中は `計算中...` を表示し、完了すると
   **Result** にメトリクス、下段 **Trajectory** に軌跡チャートが表示される。
8. エラー時は Result を更新せず、日本語のエラーメッセージを表示する。

### 3.2 軌道ウィンドウ（`orbital_app.py`）

1. **重力モデル** をプルダウンで選ぶ（**ニュートン（軌道）** / **ニュートン+J2（軌道）**。
   地表弾道の「一定」は含まない）。J2 は地球扁平の摂動を加える。
2. **軌道半径 r** のスライダーを動かす。**軌道速度 v** は「円軌道速度を自動設定」で
   `sqrt(mu/r)` に追従し、オフにすると手動指定できる。
   閉軌道では **1 周期分**（周期 × 1.05）を自動積分するため、軌道が一周して閉じる。
   このとき刻み幅は周期 / 4000 を上限に自動調整され（`dt` をそれより細かく指定しても
   上限に丸められる）、着弾前提の時間上限警告は表示しない。
3. **抗力係数 Cd** は弾道ウィンドウと同じく **0.47 に固定**。
4. **抗力（密度）モデル** を選ぶ（なし / 一様 / 指数 / 区分指数）。「なし」は抗力を
   無効化（`Cd=0`）する。**軌道計算では「なし」を推奨**する（抗力下では安定刻みが
   極端に小さくなり、発散しやすくなる）。
5. 必要に応じて **刻み幅 dt** と **adaptive** を変更する。
6. 「**シミュレーション実行**」を押すと **Result** に軌道要素（長半径・離心率など）、
   下段 **Trajectory** に軌跡チャートが表示される。
7. エラー時は Result を更新せず、日本語のエラーメッセージを表示する。

`adaptive` は刻みを安定性上限内に短縮する発散防止機構であり、精度向上を保証する
ものではありません（詳細は `range_calculator/SPEC.md` 第3章）。

### 3.3 多体ウィンドウ（`nbody_app.py`）

1. **プリセット**を選ぶ（**太陽を中心とした多体問題** / **地球を中心とした多体問題** /
    **太陽・地球・月（3体）**）。太陽中心・地球中心は中心天体 1 つだけで開始し、
    場面に合った **刻み幅 dt**・**最大時間**（太陽中心は 1 地球年、地球中心は月の
    公転周期 1 回分約 27.3 日）を自動入力する。3 体プリセットは太陽・地球・月を
    運動量相殺した初期状態で配置する。プリセット・dt・最大時間・「天体を追加」
    「最後の天体を削除」「シミュレーション実行」・エラーメッセージは**スクロール
    しない固定領域**にあり、天体グループだけがスクロールする（グリッド配置で、
    ウィンドウを縮めても実行ボタン・エラーメッセージが隠れない）。
2. 天体 1 は中心天体（初期値は座標原点・静止）で、名前・体積密度・半径・初期状態は
    自由入力で編集できる。**2 つ目以降の天体**は「**天体を追加**」で追加し、天体ごとの
    **周回対象**（先行する天体を位置で選ぶ。「天体 1」「天体 2」…と表示）と
    **天体カタログ**（太陽・惑星・月・人工衛星）を選ぶと、密度・半径と周回対象まわりの
    円軌道の初期条件（相対位置 `(+r, 0, 0)`・相対速度 `(0, sqrt(μ_host/r), 0)`）が
    読み込まれる。**高度 (m)** には周回対象の地表からの高さを指定し、軌道半径を
    周回対象の半径＋高度とする。高度は**人工衛星に限らず任意の天体**に使え、空欄なら
    カタログ既定の距離（惑星・月は主天体からの平均距離）を使う。例えば、天体 2 の
    名前と密度・半径を火星に変え、**周回対象**「天体 2」＋**天体カタログ**「月」＋
    高度を指定すると、火星の周りに月を任意の高さで置ける。周回対象の初期値は各天体の
    主天体（月・人工衛星は地球）で、先行する天体から選び直せる。これにより、太陽中心の
    系のまま地球のまわりに人工衛星を置ける。読み込み後も自由編集できる。
    天体の位置は `周回対象の座標 + (周回対象の半径 + 高度)`、速度は
    `周回対象の速度 + 円軌道速度` で与える。「**最後の天体を削除**」で天体数も変更できる
    （相互重力は全天体に働く）。
3. **μ は密度と半径から自動計算**され（μ = G·ρ·(4/3)πr³、`G = 6.67430e-11`）、
    天体グループ内に読み取り専用で表示される。
4. 「**シミュレーション実行**」を押すと計算が走り、**Result** に天体数・経過時間・
    積分ステップ数・刻み幅・時間上限・エネルギー相対変化・記録フレーム数が表示される。
    **経過時間は秒（1000 を超える値は桁区切りのカンマ付き）に加え「D日H時間M分S秒」
    （1 日未満は日を省略）でも併記**し、積分ステップ数・記録フレーム数も桁区切りで
    表示する。**dt が最短のペア周期に対して粗すぎる場合は、発散の恐れを知らせる
    警告**を Result に表示する（実行は妨げない）。**adaptive 刻み**を有効にすると
    `dt` は上限となり、各ステップを最短ペア周期の `1/ADAPTIVE_STEPS_PER_PERIOD`
    （既定 100 ステップ／周）まで短縮する。この場合の刻み幅欄は**最短刻み**の表示となり、
    粗すぎる `dt` の警告は出ない（短縮して解決するため）。
5. 完了すると下段のチャートに各天体の軌跡が描かれ、**スライダー**で任意の
    フレームへシークできる。**再生** ボタンで約 12 秒の自動再生（ループ）となる。
    **表示中心**プルダウンで、**重心（原点）**または任意の天体を基準に描画でき、
    太陽系の中の地球周回のような小さな軌道も見える。
6. 記録フレームは最大 2000 に間引かれ（高ステップ時は間隔を空けて記録するため
    メモリは一定）、推定ステップ数は 500,000 が上限。系外惑星のように多数周回する
    系を想定した上限で、超過時は日本語で dt / 最大時間の見直しを促す（adaptive 時は
    推定に最短ペア周期の上限を反映する）。
7. エラー時は Result を更新せず、日本語のエラーメッセージを表示する。

## 4. 実行ファイルのビルド（任意）

配布用の自己完結ファイルを作る場合は PyInstaller を使います。**ビルド時のみ**
必要で、アプリの実行には不要です。

```sh
pip install pyinstaller
python3 desktop/build.py
```

- Windows: `desktop/dist/range_calculator_ballistic.exe`,
  `desktop/dist/range_calculator_orbital.exe`、`desktop/dist/range_calculator_nbody.exe`
- macOS: `desktop/dist/range_calculator_ballistic`, `desktop/dist/range_calculator_orbital`,
  `desktop/dist/range_calculator_nbody`（必要なら `.app` 化）

`build.py` は 3 つの実行ファイルを生成します（弾道・軌道・多体で 1 つずつ）。物理定数の
設定ファイル（`range_calculator/config/physics_constants.json`）を全てに同梱します。
ビルド後、実行ファイルを起動して物理定数の `physics config not found` 警告が出ない
ことを確認してください。

## 5. テスト

リポジトリのルートで実行します。

```sh
python3 -m unittest discover -s desktop/tests -p "test_*.py"
python3 -m unittest discover -s range_calculator -p "test_*.py"
python3 tools/check_text_hygiene.py
```

`desktop/tests/test_agreement.py` は、`webapp` と意図的に重複させている
エラー変換・抗力係数プリセット（既定の球体 `Cd=0.47`）・simulate グルーが食い違って
いないかを検査します。
`webapp` 側を変更したら、`desktop` 側も追随させてください（詳細は
`desktop/PLAN.md` §9）。

## 7. トラブルシューティング

| 症状 | 原因 / 対処 |
|------|-------------|
| `ModuleNotFoundError: tkinter` | Python に Tk が含まれていない。python.org 版または Scoop の Python を使う |
| 起動しても何も表示されない | 追加の `pip` 依存は不要。`python3 desktop/ballistic_app.py`（または `orbital_app.py` / `nbody_app.py`）をフォアグラウンドで実行しエラーを確認する |
| `physics config not found` 警告 | 設定ファイルが見つからず組み込み既定値で動作。ビルド版では `build.py` の同梱設定を確認する |
| 計算が長い | `dt` を大きくするか `adaptive` を有効にする。`dt=0.0001`・時間上限 300 s では最大 300 万ステップになり得る |
| 軌道計算で発散する | 抗力により安定刻みが極端に小さくなる。抗力（密度）モデルを「なし」にする |
| 多体で「推定ステップ数が上限」が出る | 推定ステップ数が 500,000 を超える。`dt` を大きくするか最大時間を短くする。adaptive 刻みでは最短ペア周期で刻みが決まるため、その上限も推定に含まれる |
| 多体で「刻み幅 dt が…大きすぎます」と警告が出る | 最短のペア周期に対して `dt` が粗すぎる（発散の恐れ）。表示された目安以下に `dt` を小さくするか **adaptive 刻み**を有効にする（自動短縮され、警告は出なくなる）。低軌道の人工衛星を含めると周期が短いため警告が出やすい |
| 多体系外惑星の計算が長い | `dt` を上限として **adaptive 刻み**を有効にすると必要な分だけ短縮される。それでも長い場合は最大時間を短くする（ステップ上限は 500,000） |
| 終了時に `error messaging the mach port for IMKCFRunLoopWakeUpReliable` が出る（macOS） | macOS の入力メソッド（Input Method Kit）が出力する**無害なシステムログ**。テキスト入力欄にフォーカスがある状態で終了すると表示され、アプリ側の問題ではないため無視してよい（Electron / Java Swing / Blender など多数の macOS アプリでも発生する） |
